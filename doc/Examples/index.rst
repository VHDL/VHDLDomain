.. _EX:

Examples
########

Each example is a VHDL design of :file:`examples`, read by pyGHDL.dom (see :ref:`CONFIG`) and described by the
directives of the domain (see :ref:`DIR`): the rendering of a directive next to the VHDL source, whose documentation
comments it shows, and the reStructuredText of the directive.

StopWatch
  A stop watch counting seconds and minutes on a 7-segment display: packages with types, constants, subprograms,
  a protected type and components, contexts, entities with generics and ports, and a configuration.

An example page is built where pyGHDL is installed; without it, the page is left out.
